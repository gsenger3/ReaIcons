# Primo ReaIcon Collection

Welcome to the **Primo Studios ReaIcon Collection**. This is a collection of icons created for the custom Primo Studios Reaper Scripts. The icons are a set of Reaper Toolbar icons designed for use with the [Reaper](https://www.reaper.fm) Digital Audio Workstation. The collection includes the master source template in Pixelmator (Pxd) format and the 3 Reaper supported resolutions of transparent png icon strips.

## Master Template

The source of truth for all icons in this repository is the master template file. If you need to make  changes to any of the included icons edit this file:

- **File:** `Reaper Toolbar Icon Template.pxd`
- **Format:** Pixelmator Pro (PXD)
- **Note:** This file contains all icons organized into layers/artboards for streamlined exporting.

## How to Use

- Copy the `[icon_name]_90.png` to `[Reaper Resource Path]/Data/toolbar_icons`
- Copy the `[icon_name]_150.png` to `[Reaper Resource Path]/Data/toolbar_icons/150`
- Copy the `[icon_name]_200.png` to `[Reaper Resource Path]/Data/toolbar_icons/200`
